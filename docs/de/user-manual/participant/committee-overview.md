# Gremienübersicht & Status

## Die Gremienübersicht

Nichtstaatliche Akteure und Beobachter:innen sehen nach dem Öffnen der Konferenz aus dem Launcher eine Übersicht aller Gremien der Konferenz. Jede Kachel zeigt Name, Abkürzung, aktiven Tagesordnungspunkt und aktuellen Status des Gremiums auf einen Blick, damit du schnell findest, wo du hinmusst, ohne jedes Gremium einzeln zu öffnen. Delegierte überspringen diese Übersicht und kommen direkt in ihr eigenes Gremium.

## Gremienstatus verstehen

Der Vorsitz führt ein Gremium im Lauf einer Sitzung durch fünf Status. Als Teilnehmende:r erkennst du am Status, welche Art von Beteiligung gerade von dir erwartet wird:

| Status                            | Was das für dich bedeutet                                                                                                         |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **Formale Debatte**               | Die allgemeine Redeliste läuft. Delegierte können ums Wort bitten, und die Reden folgen nacheinander.                             |
| **Moderierte informelle Sitzung** | Eine strukturierte, vom Vorsitz geleitete Diskussion zu einem bestimmten Unterthema, mit eigener Redeliste und kürzerer Redezeit. |
| **Informelle Sitzung**            | Freie Zeit, in der Delegierte direkt verhandeln. Es ist keine Redeliste aktiv.                                                    |
| **Vertagung**                     | Die Sitzung ist unterbrochen (z. B. eine Pause). Bis es weitergeht, wird nichts von dir erwartet.                                 |
| **Pause**                         | Eine kurze Unterbrechung, oft zwischen Tagesordnungspunkten oder während der Vorsitz etwas vorbereitet.                           |

Jeder Status kann eine Überschrift (z. B. das Thema der moderierten Sitzung) und einen Countdown haben, falls der Vorsitz eine Dauer festgelegt hat. Beides siehst du auf deinem Dashboard.

## Tagesordnungspunkte

Ein Gremium kann mehrere Punkte auf der Tagesordnung haben, aktiv ist aber immer nur einer. Der Titel des aktiven Tagesordnungspunkts steht auf deinem Dashboard und bestimmt, welche Redeliste, Resolutionen und Abstimmungen gerade relevant sind.

## Der geteilte Präsentationsbildschirm

In den meisten Gremienräumen läuft eine geteilte **Präsentationsansicht** auf einem Projektor. Du bedienst sie nicht selbst, aber es hilft zu wissen, was sie zeigt, denn sie ist die gemeinsame Referenz des Raums:

- Aktuelle:r Redner:in und die verbleibende Redezeit
- Die Redeliste
- Die Aufteilung nach Regionalgruppen, falls aktiviert
- Die aktive Resolution (bei der Arbeit an Resolutionen) oder Ergebnisse von Anwesenheitsfeststellung und Abstimmungen, je nachdem, was der Vorsitz gerade durchführt

Bist du dir unsicher, was gerade passiert, schau auf den Projektor. Er zeigt denselben Live-Status wie dein eigenes Dashboard.

## Mehrheiten auf einen Blick {#majorities-at-a-glance}

Die Karte **Mehrheiten** auf deinem Dashboard zeigt vier Zahlen, basierend darauf, wer gerade als anwesend markiert ist. Fahre mit der Maus über eine Kachel oder tippe darauf, um zu sehen, was sie bedeutet.

- **Anzahl anwesender Staaten**: wie viele Delegationen als anwesend markiert sind.
- **Einfache Mehrheit**: die Stimmen, die für mehr Dafür- als Dagegen-Stimmen nötig sind.
- **Zweidrittelmehrheit**: die Stimmen, die für eine Zweidrittelmehrheit nötig sind.
- **Unterstützer für Änderungsanträge**: wie viele unterstützende Delegationen ein Änderungsantrag braucht, bevor er eingereicht werden kann (siehe [Änderungsanträge](./amendments)).

Diese Zahlen aktualisieren sich automatisch, sobald Delegierte ein- oder auschecken, und spiegeln so immer den aktuellen Stand im Raum wider.
