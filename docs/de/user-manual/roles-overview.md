# Rollenübersicht

CHASE weist jeder Person pro Konferenz genau eine Rolle zu. Sie bestimmt, was die Person sieht und tun kann.

## Verfügbare Rollen

| Rolle                                  | Beschreibung                                                                                                                   |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **Admin**                              | Voller Zugriff auf Mission Control für eine Konferenz: Gremien, Delegationen, NAs, Nutzer:innen.                               |
| **Teammitglied** (Vorsitz)             | Kann jedes Gremium der Konferenz öffnen und leiten: Redeliste, Abstimmungen, Anträge, Resolutionen, Anwesenheit.               |
| **Delegierte\*r**                      | Vertritt eine bestimmte Delegation in einem Gremium. Redet, stimmt ab, stellt Anträge, entwirft Resolutionen.                  |
| **Nichtstaatliche\*r Akteur\*in (NA)** | Vertritt eine Organisation statt eines Landes, wird meist per gedrucktem QR-Badge eingecheckt. Kann zwischen Gremien wechseln. |
| **Beobachter\*in**                     | Nur-Lese-Zugriff auf ein Gremium, ohne Delegation.                                                                             |

Admins können alles, was ein Teammitglied kann. Ein Admin kann also auch ein Gremium leiten.

Hat ein Gremium [Anträge](./chair/requests) eingeschaltet, können Delegierte und NAs Anträge an den Vorsitz stellen. NAs können keine Antragsarten nutzen, die als **Nur Delegierte** markiert sind, und Beobachter:innen können gar keine Anträge stellen. Welche Antragsarten es gibt, legen nur Admins fest.

Delegierte, Beobachter:innen und NAs werden in dieser Dokumentation zusammen als **[Teilnehmende](./participant/getting-started)** behandelt, weil ihr Alltag in CHASE weitgehend gleich ist.

## Eine separate, höhere Ebene: Global-Admin

Über die Rollen pro Konferenz hinaus kann die Person, die eure CHASE-Instanz betreibt, zusätzlich **Global-Admin**-Zugriff vergeben. Damit kann jemand komplett neue Konferenzen anlegen und jede Konferenz auf der Instanz verwalten, nicht nur die, zu denen er oder sie ausdrücklich hinzugefügt wurde. Den Unterschied erklärt der [Leitfaden für Admins](./admin/getting-started).

## Deine Rolle prüfen

Dein Rollen-Badge steht im Avatar-Menü oben auf jedem CHASE-Bildschirm. Wenn es nicht stimmt, kann ein Admin es unter [Benutzer & Rollen](./admin/users-roles) korrigieren.
