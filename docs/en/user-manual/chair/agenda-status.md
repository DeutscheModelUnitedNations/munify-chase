# Agenda & State of Debate

CHASE tracks three independent things about where your committee is right now. Don't confuse them: they're set separately and shown together in the status card on every chair page.

## Agenda Item

A simple dropdown of every agenda item on your committee's agenda, plus a **+** button to add a new one (type its title into the prompt). Switching the active agenda item is instant and drives which speakers list, resolutions, and votes are currently "the" active ones.

## Status

The committee's formal status, reachable via **Alt+S** from anywhere or in the **Change status** card on the Set up page. The status tabs show icons, so hover them to see the name:

- **Formal debate**: the general speakers list is running.
- **Informal meeting**: free negotiation time, no active speakers list.
- **Moderated informal caucus**: a structured discussion, if your conference has this status enabled.
- **Pause**: a brief hold.
- **Suspension**: the session is paused (e.g. a break).

When you open the changer, it suggests **Informal meeting** if you are in formal debate and **Formal debate** otherwise.

Every status gets an end time. Pick it with the quick grids (absolute: jump to minute :00, :05, :10 and so on of this or the next hour, relative: 3, 5, 10, 15, 20, 25 or 30 minutes from now), type it into the `HH:MM:SS` field, or nudge it with the minus and plus buttons by one minute. You can also override the displayed name with a custom headline. Click **Set status** to apply. CHASE won't let you pick a time already in the past.

## State of Debate

A free-text label describing _what's actually being discussed_ right now (e.g. "General debate", "Debate on the draft resolutions", "Vote on each operative paragraph"), separate from Status. A searchable box offers common presets, but you can type anything. Save with **Save debate status**. The trash icon empties the field, so save afterwards to clear it for everyone.

:::tip
Status tells the room what mode you're in. State of Debate tells them what topic that mode is about. Set both so participants' dashboards and the projector both make sense at a glance.
:::
