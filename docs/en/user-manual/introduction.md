# Introduction to CHASE

**CHASE** (CHAiring SoftwarE) is MUNify's conference management software, built by Deutsche Model United Nations (DMUN) e.V. to run Model United Nations committee sessions digitally, from the first roll call to an adopted resolution.

## What is CHASE?

CHASE provides digital tools for managing the core activities of MUN committee sessions:

- **Speakers Lists**: manage speaker queues and Points of Information digitally, with live timers
- **Digital Voting**: show-of-hands, roll-call, and device-based votes
- **Working Papers & Resolutions**: a real-time collaborative editor with sponsorship, amendments, and clause-by-clause voting
- **Attendance & Roll Call**: presence tracking with live majorities, roll calls, and NSA badge scanning
- **Requests**: delegates and NSAs send points and motions to the chairs digitally, and chairs resolve them from a queue
- **Presentation Mode**: a shared projector view kept in sync with everything happening in the room
- **Statistics**: attendance, speaking time, and fairness metrics for the whole conference

## Who Uses CHASE?

CHASE is designed for three primary audiences:

| Role            | Description                                                                                               |
| --------------- | --------------------------------------------------------------------------------------------------------- |
| **Participant** | Delegates, spectators, and non-state actors (NSAs) who speak, vote, and (where enabled) draft resolutions |
| **Chair**       | Committee chairs who run debate, speakers lists, voting, and resolutions for their committee              |
| **Admin**       | Conference organizers who set up committees, delegations, and users in Mission Control                    |

:::tip Role Intersections
Many users hold multiple roles. A Secretariat member might have Admin access while also chairing a committee. See [Roles Overview](./roles-overview) for how permissions combine.
:::

## Technical Requirements

CHASE is a web application that works in modern browsers (Chrome, Firefox, Safari, Edge). No installation is required: simply open the URL your conference organizers provide. A native desktop app is also available for Windows, macOS, and Linux for a more integrated experience.
