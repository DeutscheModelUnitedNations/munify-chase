# Pedidos

Com os pedidos, os delegados e os ANE podem enviar pontos e moções (por exemplo um Direito à Informação ou uma Votação Nominal) à presidência a partir do seu próprio dispositivo. Como administrador, decide que tipos de pedido existem. A presidência de cada comité decide se o seu comité aceita pedidos.

## O separador Pedidos

Abra **Configuração** e mude para o separador **Pedidos**. Cada tipo de pedido ocupa uma linha:

- As setas **Mover para cima** / **Mover para baixo** definem a ordem. A presidência vê os pedidos pendentes ordenados por esta ordem, por isso coloque os tipos mais urgentes no topo.
- **Ícone**: um nome de ícone Font Awesome, como `fa-flag`.
- **Nome**: o que os delegados veem no botão.
- **Ativado**: desligue um tipo para o ocultar sem o eliminar.
- **Apenas delegados**: quando está ligado, os ANE não podem fazer este pedido.
- O ícone do caixote do lixo remove o tipo depois de uma confirmação.

As alterações são guardadas assim que edita um campo.

![O separador Pedidos com os tipos de pedido, os respetivos ícones e os interruptores Ativado e Apenas delegados](shot:admin/requests-tab)

Por baixo da tabela há dois botões:

- **Carregar conjunto padrão** adiciona o conjunto padrão da DMUN com 15 tipos de pedido. Os direitos pessoais, a Votação Nominal e a Sessão Informal estão abertos aos ANE. Todas as outras moções processuais ficam definidas como **Apenas delegados**. Os tipos cujo nome já existe são ignorados, por isso pode clicar mais do que uma vez sem problemas. Os nomes são criados no idioma em que está a usar o CHASE.
- **Adicionar pedido** adiciona uma linha vazia com um ícone de bandeira para um tipo seu.

Também pode configurar os tipos de pedido ao criar uma conferência, no passo **Pedidos** do [assistente de importação](./importing-delegator).

## Ativar os pedidos num comité

Os pedidos estão desligados em todos os comités por predefinição. A presidência ativa-os na página de configuração do seu comité com a definição **Pedidos** (consulte [Pedidos para a presidência](../chair/requests)). Os delegados e os ANE encontram-nos depois na vista do seu comité (consulte [Pedidos para participantes](../participant/requests)).

## Bom saber

- Cada pessoa só pode ter um pedido pendente por tipo num comité. Depois de resolvido ou retirado, pode enviá-lo de novo.
- Os delegados só podem enviar pedidos ao comité em que têm lugar. Os ANE podem enviá-los a qualquer comité.
- Só os administradores podem alterar os tipos de pedido.
