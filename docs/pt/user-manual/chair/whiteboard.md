# Quadro branco

Cada comité tem um quadro branco partilhado que pode usar para mostrar algo a toda a sala: um horário, uma imagem carregada ou uma ligação que se lê com o telemóvel.

## Editar

Na página **Configurar**, clique em **Editar** no cartão do quadro branco para abrir o editor, uma superfície de texto formatado com uma barra de formatação (títulos, listas, etc.) e um menu flutuante para formatação rápida quando seleciona texto.

![A janela do editor do quadro branco, com a barra de formatação e uma área de escrita vazia](shot:chair/whiteboard-editor)

Duas ferramentas especiais:

- **Imagem**: insere uma imagem, com **Enviar** a partir do seu dispositivo ou a partir de um **URL**, e depois **Inserir imagem**.
- **Gerar Código QR**: insere um código QR. Escolha **Para o comité** para ligar ao seu comité (**Visão do participante** ou **Para os documentos de trabalho**), ou **URL Personalizada** para ligar a qualquer outro endereço, e depois clique em **Usar Este Código QR**.

Quando terminar, clique em **Publicar alterações** para pôr o quadro em direto, ou em **Cancelar** para descartar as alterações.

## Visibilidade

Nos painéis dos participantes, o quadro branco aparece assim que tem conteúdo e desaparece quando o apaga. No ecrã de apresentação, o **Esquema de apresentação Padrão** e o **Esquema de apresentação para Telas Pequenas** incluem sempre um mosaico do quadro branco, que mostra um marcador de posição enquanto o quadro está vazio. Quando há um projeto de resolução ativo, o ecrã de apresentação muda para o esquema da resolução, que não tem quadro branco.
