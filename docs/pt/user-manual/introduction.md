# Introdução ao CHASE

O **CHASE** (CHAiring SoftwarE) é o software de gestão de conferências do MUNify, desenvolvido pela Deutsche Model United Nations (DMUN) e.V. para conduzir digitalmente as sessões dos comités de Model United Nations, desde a primeira chamada até à resolução adotada.

## O que é o CHASE?

O CHASE oferece ferramentas digitais para gerir as atividades centrais das sessões de um comité MUN:

- **Listas de Oradores**: gestão digital das filas de oradores e dos Pontos de Informação, com cronómetros em tempo real
- **Votação digital**: votações por levantamento de mãos, nominais e por dispositivo
- **Documentos de trabalho e resoluções**: um editor colaborativo em tempo real com patrocínios, emendas e votação cláusula a cláusula
- **Presença e Chamada**: registo de presença com maiorias em tempo real, chamadas e leitura dos crachás dos ANE
- **Pedidos**: os delegados e os ANE enviam pontos e moções à presidência por via digital, e a presidência resolve-os a partir de uma fila
- **Modo de apresentação**: uma vista partilhada para o projetor, sempre sincronizada com tudo o que acontece na sala
- **Estatísticas**: presença, tempo de fala e métricas de equidade para toda a conferência

## Quem usa o CHASE?

O CHASE foi pensado para três públicos principais:

| Função            | Descrição                                                                                                     |
| ----------------- | ------------------------------------------------------------------------------------------------------------- |
| **Participante**  | Delegados, espectadores e atores não estatais (ANE) que intervêm, votam e (quando ativado) redigem resoluções |
| **Presidência**   | Quem preside aos comités e conduz o debate, as Listas de Oradores, as votações e as resoluções do seu comité  |
| **Administrador** | Organizadores da conferência que configuram comités, delegações e utilizadores no Controlo de Missão          |

:::tip Funções combinadas
Muitos utilizadores têm várias funções. Um membro do Secretariado pode ter acesso de Administrador e, ao mesmo tempo, presidir a um comité. Consulte a [Visão geral das funções](./roles-overview) para ver como as permissões se combinam.
:::

## Requisitos técnicos

O CHASE é uma aplicação web que funciona nos navegadores modernos (Chrome, Firefox, Safari, Edge). Não é preciso instalar nada, basta abrir o endereço indicado pelos organizadores da conferência. Existe também uma aplicação nativa para Windows, macOS e Linux, para uma experiência mais integrada.
